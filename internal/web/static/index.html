Two tunnels are on the same WAN

Each tunnel is supposed to ride its own internet service. These are arriving from one public address, so there is only one link underneath them — they will fail together, and failing over from one to the other achieves nothing.

On pfSense: policy-route each tunnel to a single gateway, never a gateway group, and set gateway monitoring action to disabled for each gateway. By default pfSense withdraws the policy route for a gateway it thinks is down and the traffic falls through to the default one, which is exactly this.
